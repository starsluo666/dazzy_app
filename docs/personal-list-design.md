# 个人列表页统一规范

2026-09-29，按用户选择的 Apple 方向 1 实现；继续沿用 `DzNavBar`，不引入重复大标题。

## 范围与组件

覆盖我的订单、我的优惠券、我的活动、通知中心、浏览记录、我的收藏。
大厅、详情、支付及表单页面不受影响，接口、状态映射和业务动作保持原逻辑。

- `DzListFilters`：`chips` 用于单行独立状态按钮；`tabs` 用于同级内容切换；`compact` 用于次级状态。
- `DzListEmpty`：统一功能图标、标题、辅助说明和可选动作，不为没有明确下一步的页面添加按钮。
- `styles/lists.scss`：仅通过 `dz-list-page` 等显式类应用白色页面、间距、吸顶筛选和剩余视口空状态。

## 设计与交互

- 强调色 `#08787e`、说明文字 `#5e6b72`，选中态不使用黑色。
- 状态按钮不换行；窄屏采用原生横向滚动，首次带筛选参数进入及后续切换时露出选中项。
- 所有新增按钮触控区至少 44×44px；活动次级按钮视觉高度 30px。
- 同级内容切换使用文字与青色下划线；活动次级选中态为浅青底。
- 空状态图标 40px，无装饰底框；标题至少 18px、说明至少 14px。
- 网页端按钮可聚焦并通过 Enter/空格激活，使用 `aria-pressed` 表达选择；保留可见焦点。
- 减少动态模式取消按压缩放；高对比度模式为筛选按钮补充轮廓。
- 优惠券零计数显示为 0，历史仍包含占用、使用、过期、撤销状态。
